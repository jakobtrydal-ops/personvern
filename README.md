# Personvern / privacy

Personvernerklæringer for appene mine i Google Play, publisert med GitHub Pages fra `main`.

| App | Mappe | Adresse |
|---|---|---|
| BibelQuiz | flyttet til Cloudflare (`bibelquiz/` videresender) | https://bibelquizweb.jtapps9.workers.dev/personvern/ |
| David and Goliath | `david-and-goliath/` | https://jakobtrydal-ops.github.io/personvern/david-and-goliath/ |
| Oppgavetavla / ChoreBoard | `oppgavetavla/` | https://jakobtrydal-ops.github.io/personvern/oppgavetavla/ |
| Pilgrim Rush | `pilgrim-rush/` | https://jakobtrydal-ops.github.io/personvern/pilgrim-rush/ |

Forsiden (`index.html`) lister alle appene. Ny app: lag en ny mappe med en `index.html` og legg den til i lista. Ikke endre navn på mapper som er registrert i Google Play.
